# 구간 안정성 — 전체 구간 하나로는 못 보는 것

전체 구간(2022-01~2026-03) 결과만 보면 스코어러는 "유니버스와 사실상 같다"
(6개월 +0.12p)로 읽힌다. 구간을 절반으로 잘라보니 **그 숫자는 서로 반대인 두
결과의 평균**이었다.

## 먼저 — 이 표를 어떻게 읽어야 하는가

유효 시점이 구간당 **4.0~4.5개**뿐이다(6개월 기준, 겹치는 창 보정 후). 이 크기로는
어느 쪽 구간도 잡음과 구분되지 않는다. 그래서 아래 표의 결론은 **"뒤 구간이 좋다"가
아니라 "구간에 따라 부호가 뒤집힌다"** 이다.

## TOP5 — 부호가 뒤집힌다

| 구간 | 3개월 적중률 / 중앙초과 | 6개월 적중률 / 중앙초과 | 유효 시점(6M) |
|---|---|---|---|
| 앞 (2022-01~2024-03) | **-7.2%p** / **-2.78p** | **-7.7%p** / **-3.81p** | 4.5 |
| 뒤 (2024-04~2026-03) | **+3.0%p** / **+1.05p** | **+10.7%p** / **+9.29p** | 4.0 |
| 전체 | -2.5%p / -1.69p | +1.9%p / +0.12p | 8.5 |

전체의 +0.12p 는 -3.81p 와 +9.29p 를 섞은 값이다. **안정적으로 "같다" 가 아니라,
구간마다 크게 다른 것을 평균해서 0 근처가 된 것이다.**

뒤 구간의 +9.29p 를 성과로 읽으면 안 된다. 유효 시점 4개이고, 같은 방법으로 앞
구간을 보면 -3.81p 가 나온다. 둘 중 하나를 고를 근거가 없다.

## 개별 축 — 이쪽은 부호가 안 뒤집힌다

TOP5 와 달리, 축을 하나씩 떼어 보면 **네 칸(2구간 × 2기간) 전부 같은 부호**다.

**52주 고점比** — 스코어러는 깊게 눌릴수록 점수를 준다

| | 3개월 | 6개월 |
|---|---|---|
| 앞 | +1.07p | +2.67p |
| 뒤 | +5.37p | +4.54p |

전부 양수 = **고점 근처가 깊게 눌린 쪽보다 항상 나았다.** 스코어러는 반대로
점수를 준다(가격 미반영 30점). 크기는 구간마다 다르지만 방향은 한 번도 안 뒤집혔다.

**분기TTM 헤게모니 스프레드** — 스코어러는 높을수록 점수를 준다

| | 3개월 | 6개월 |
|---|---|---|
| 앞 | +0.42p | +2.61p |
| 뒤 | +4.33p | +8.92p |

전부 양수 = **방향이 맞다.** 품질 축은 스코어러가 거는 방향대로 간다.

## 정정 — 60일 변동성은 과대평가였다

전체 구간 팩터 스캔에서 **30번 중 유일하게 세 관문을 통과**한 지표였다. 구간을
쪼개니 가장 불안정하다.

| | 폭(6M) | 단조성 ρ |
|---|---|---|
| 전체 | -7.66p | **-1.0** |
| 앞 | -6.23p | -1.0 (반쪽 탈락) |
| 뒤 | -5.81p | **-0.3** ← 모양이 깨진다 |

부호는 늘 음수지만 단조성이 유지되지 않는다. **전체 구간의 통과는 두 구간을 합쳐서
생긴 것이다.**

관문을 통과한 것이 가장 견고한 게 아니었고, 통과하지 못한 둘(스프레드·고점比)이
오히려 부호 안정성이 높았다. 관문이 **단조성·폭만 보고 시간에 걸친 안정성은 안
보기 때문**이다. 관문을 고쳐 통과시키는 대신, 이 한계를 적어 둔다.

## 그래서 무엇이 남는가

1. **합성 점수는 구간에 따라 뒤집힌다.** 화면의 점수를 "이 정도 성과가 기대된다"로
   읽을 근거가 없다.
2. **개별 축의 방향은 안 뒤집힌다.** 스프레드는 맞는 방향, 52주 고점比는 반대 방향.
3. 1과 2를 같이 놓으면 하나의 **가설**이 선다 — 합성 점수가 흔들리는 것은 방향이
   맞는 축과 거꾸로 걸린 축을 섞었고, 둘의 영향력이 국면마다 달라지기 때문일 수 있다.
   **측정한 것이 아니라 추론이다.**

## 하지 않은 것

배점을 뒤집어 다시 돌리지 않았다. 같은 데이터에 맞추면 반드시 좋아지고, 그건
검증이 아니라 과최적화다. 이 가설을 확인하려면 **다른 시장(미국판)** 이 필요하다.

# 하락 국면별 백테스트 — 미국

고점比 축이 진짜 역방향인지, 아니면 특정 하락 국면에서만 그렇게 보이는지
가리기 위해 성격이 다른 다섯 하락장을 따로 쟀다. `<국면>-base.md` 는 화면
기본 배점, `<국면>-alt.md` 는 `--weights '{"fromHigh":0}'`.

**판정 기준은 결과를 보기 전에 정했다** — 넷 이상에서 이기면 축 자체의
문제, 2022 에서만 크게 이기면 국면 의존, 부호가 뒤집히는 국면이 있으면 전부
보류. (2022 는 기존 미국 백테스트가 보던 구간이라 일부러 넣었다.)

| 국면 | 구간 | 6개월 중앙 초과차: 기본 → 고점比0 |
|---|---|---|
| 2011 유럽위기 | 2011-01~2012-06 | +1.40p → **+2.73p** |
| 2015 차이나쇼크 | 2014-07~2016-12 | −5.04p → **−1.90p** |
| 2018 4분기급락 | 2018-01~2019-06 | +3.24p → **+6.13p** |
| 2020 코로나 | 2019-07~2021-06 | −0.38p → −0.20p |
| 2022 긴축 | 2021-07~2023-12 | −1.71p → **+1.22p** |

**6개월 중앙 초과 기준 5/5 개선, 3개월 4/5**(2011 은 완전 동일). 지는 국면이
하나도 없다.

국면 의존 혐의는 걷혔다. 2022 는 오히려 중간이고, 가장 크게 이긴 것은
2018 4분기 급락이다. 유럽 재정위기·원자재 쇼크·금리 발작·팬데믹·긴축 —
성격이 전혀 다른 다섯 하락장에서 같은 방향이 나오는 것을 '그 국면의 성질'
로는 설명할 수 없다.

## 2020 만 다르다 — 반증이 아니라 메커니즘 설명

2020 은 사실상 무효다(6개월 +0.18p, 3개월 +0.04p). 2020년 3월은 한 달 만에
전 종목이 같이 빠졌다가 같이 튄 국면이라, '고점 대비 얼마나 빠졌나' 가 종목을
구분하지 못하는 유일한 유형의 하락이었다. 축을 꺼도 켜도 차이가 없는 게
당연하다.

즉 축이 정보를 담는 국면에서는 그 정보가 역방향이었고, 정보를 안 담는
국면에서는 아무 영향이 없었다. 가설과 어긋나는 게 아니라 들어맞는다.
